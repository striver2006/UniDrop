# UniDrop 用户使用手册 (User Guide)

欢迎使用 **UniDrop (UniClip)** —— 极速、安全且原生的跨平台剪贴板与文件分发工具。

本文档将引导您从零开始熟悉 UniDrop 的界面操作、网络配置、设备协同以及最核心的**“远端传输完成后直接在本地 Ctrl+V / Cmd+V 粘贴”**的原生剪贴板黑科技体验。

---

## 1. 核心亮点与工作机制

UniDrop 与传统文件传输工具（如网盘、微信文件传输助手、隔空投送）相比，最大的革新在于：
* **原生剪贴板无感装载**：接收端下载校验完毕后，直接将文件句柄注入操作系统剪贴板（Windows `CF_HDROP` / macOS `fileURL` / Linux `text/uri-list`）。您无需在繁琐的“下载文件夹”里翻找，直接在目标目录按 **`Ctrl + V`** (Windows/Linux) 或 **`Cmd + V`** (macOS) 即可瞬间落地粘贴！
* **企业级零泄露安全**：传输走加密中继通道，支持 HMAC 盐化接入、PathGuard 防目录穿越沙盒防护、整文件 SHA-256 完整性核验。
* **超轻量常驻**：后台常驻仅需 20~30MB 物理内存，低功耗静默运行。

## 2. 首次配置与偏好设置

首次安装并启动 UniDrop 后，客户端会常驻在桌面系统托盘中：

### 2.1 托盘与窗口唤出
* **左键点击托盘图标**：唤出或收起 UniDrop 主面板；
* **右键点击托盘图标**：呼出系统托盘菜单，支持“显示主窗口”与“退出 UniDrop”；
* **窗口拖动**：UniDrop 采用精致现代的无边框设计，鼠标点击主面板顶部深色标题栏区域即可随意拖拽停靠在屏幕任意位置。

### 2.2 配置中继服务器与密钥 (PSK)
点击面板右上角的 **齿轮（偏好设置）图标**，弹出“连接与安全偏好”设置窗口：

```text
+------------------------------------------------------+
| 🛡️ 连接与安全偏好                                   [X] |
+------------------------------------------------------+
| 公网中继服务器地址 (WSS/WS)                          |
| [ wss://unidrop.yourdomain.com                     ] |
|                                                      |
| 账号标识 (Account ID)                                |
| [ my_team_sync                                     ] |
|                                                      |
| 预共享密钥 (PSK Secret Key)                          |
| [ ************************************************ ] |
|                                                      |
| [X] 静默自动装载剪贴板                              |
|     免去点击系统通知，传输完成后直接写入系统剪贴板    |
|                                                      |
|            [  取 消  ]     [ 保存配置 ]              |
+------------------------------------------------------+
```

1. **公网中继服务器地址**：
   * 本地测试默认填 `ws://127.0.0.1:8080`；
   * 生产环境填写您自己搭建或团队提供的安全地址（如 `wss://unidrop.yourdomain.com`）。
2. **账号标识 (Account ID)**：
   * 需协同流转的多台设备必须填入**相同的 Account ID**，以归属在同一个安全工作区内。
3. **预共享密钥 (PSK Secret Key)**：
   * 填入中继服务器预设的高强度密钥字符串。
4. **静默自动装载剪贴板**（强烈推荐勾选）：
   * 开启后，远端传来的文件一经下载核验完成，无需手动点击，直接写入本地系统剪贴板。
5. 点击 **“保存配置”** 并重启客户端使新网络配置生效。

> [!TIP]
> 如果顶部出现红色横幅提示 **“鉴权失败: signature mismatch / timestamp expired”**，说明密钥填写有误或本机系统时间与服务器误差超过 60 秒，请点击“检查密钥”重新校对。

## 3. 在线设备发现与状态感知

当配置生效且与中继服务器建立 WSS 长连接后：
* 主面板下方的连接状态将亮起绿灯：**“PSK 接入安全就绪”**；
* 本机信息行展示：`本机: 主机名 (操作系统类型)`；
* “在线协同设备”区域将实时列出当前局域网或公网中同一 Account ID 下的其他在线设备：
  * 每台设备展示：主机名、系统标识徽章（如 `MAC` / `WINDOWS` / `LINUX`）、在线状态绿点；
  * 右侧带有 **“发送文件”** 操作按钮。

---

## 4. 发送文件与目录操作

### 方式一：拖拽文件（最便捷）
1. 在“在线协同设备”列表中，找到要接收文件的目标设备，点击 **“发送文件”**；
2. 弹出“发送文件”窗口；
3. 直接从系统访达（Finder）或文件资源管理器中，将一个或多个文件/文件夹**拖拽到弹窗中**；
4. 弹窗将立即捕获路径并显示在“待发送列表”中；
5. 点击 **“开始发送”**，后台将自动进行哈希计算、分块封包，并通过流水线滑动窗口高速中继发往目标端。

### 方式二：手动输入或粘贴绝对路径
1. 在弹窗输入框中，直接粘贴目标文件的绝对路径（如 `/Users/name/Documents/report.pdf` 或 `D:\Photos\photo.jpg`）；
2. 点击 **“添加”** 或直接按下键盘 **`Enter` 回车键**；
3. 支持添加多个文件或目录进行批量打包传输；
> [!NOTE]
> **关于文件夹传输说明**：当前 v0.1.0 版本核心聚焦于常规单/多文件的高速无感流转；若直接选择文件夹，客户端为保证路径安全性会自动跳过目录项。如需分发大型目录，建议先压缩为 `.zip` 或 `.tar` 后发送。

## 5. 接收文件与剪贴板无感粘贴落地

当远端设备向您发起文件流转时：

1. **请求与进度感知**：
   * 屏幕右上角将弹出系统原生提示：`收到传输请求: X 个文件`；
   * UniDrop 主面板上方的“当前传输”列表自动展示该会话条目，并实时刷新动态传输进度条（已传输字节数、百分比、传输中状态）。
2. **下载核验**：
   * 接收端自动通过流水线滑动窗口拉取分块，并由 PathGuard 过滤恶意逃逸路径，落入安全沙盒缓存目录，完成 SHA-256 全量哈希比对。
3. **原生剪贴板注入与落地**：
   * **情况 A（已勾选“静默自动装载剪贴板”）**：
     * 传输进度显示 100% 完成后，系统托盘弹出绿色成功通知：`传输完成，已装载至系统剪贴板`。
     * **此时您只需要：打开任意文件夹或桌面，直接按下 `Ctrl + V`（Windows/Linux）或 `Cmd + V`（macOS），文件即刻从剪贴板粘贴落地！**
   * **情况 B（未勾选自动装载）**：
     * 传输完成后，卡片上将显示 **“装载到剪贴板”** 按钮；
     * 鼠标点击该按钮，即可随时将该会话的文件装入系统剪贴板，随时随处粘贴。

## 6. 本地缓存与空间管理

* **沙盒缓存目录**：
  * UniDrop 会将中转的文件临时存放在系统专用的应用程序缓存沙盒内：
    * **macOS**: `~/Library/Caches/UniDrop/cache/`
    * **Windows**: `%LOCALAPPDATA%\UniDrop\cache\`
    * **Linux**: `~/.cache/unidrop/cache/` (或 `$XDG_CACHE_HOME/unidrop/cache/`)
* **剪贴板免疫锁与自动老化清理**：
  * **2 小时剪贴板免疫保护锁**：凡是被装载至系统剪贴板的文件，在 2 小时内受强制免疫保护，任何自动清理进程均不会将其误删，防止用户尚未粘贴时文件被回收；
  * **定期 GC 与容量水位保护**：客户端后台守护进程每小时运行一次清理。默认 TTL 为 24 小时；当缓存总量达到 10GB 高水位线时，将自动按 LRU 顺序缩容清理至 8GB 安全低水位。

## 7. 常见问题排查与 FAQ

### Q1: 在线协同设备列表中看不到另一台电脑？
1. 请确认两台设备的 **服务器地址 (Server URL)**、**Account ID** 和 **预共享密钥 (PSK)** 完全一致；
2. 检查两台设备是否都能正常访问中继服务器（例如可以在浏览器或终端测试 `http://server_ip:8080/healthz` 是否返回 200 OK）；
3. 点击主界面右上角的 **“刷新”** 按钮主动拉取最新的在线列表。

### Q2: 提示“传输完成”，但按 Ctrl+V / Cmd+V 没有反应？
1. **系统权限检查**：
   * 在 macOS 上，请确认已在“系统设置 -> 隐私与安全性 -> 辅助功能”中允许了 UniDrop 访问；
   * 在 Linux 上，请确认已根据安装手册安装了 `xclip`（X11 用户）或 `wl-clipboard`（Wayland 用户）。
2. **剪贴板被后续操作覆盖**：
   * 如果在传输完成之后，您又在本地按了 `Ctrl+C` 复制了其他文字或文件，剪贴板会被新内容覆盖。此时只需在 UniDrop 主面板的传输记录中，重新点击 **“装载到剪贴板”** 按钮即可重新恢复。

### Q3: 传输超大文件（数 GB）会不会把内存撑爆？
* 不会。UniDrop 无论在服务端还是客户端，均采用 **4MB 分块流式管道（Streaming Pipeline）** 和固定大小的滑动窗口设计，零磁盘内存透传。传输时内存开销平稳受控在 30MB~50MB 左右，支持大文件稳定无损流转。
